# Framelift: module APIs (integration contract)

The public surface of each module. Shared types are in `Sources/Framelift/Shared/Contracts.swift`, and the C ABI is in `Sources/VeyraCore/include/VeyraBridge.h`.

Target: macOS 26+ on Apple Silicon. Swift 6 toolchain in Swift 5 language mode. Use `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` for every build command. The Metal offline compiler is **not installed**, so `.metal` sources are compiled at runtime with `device.makeLibrary(source:options:)` from the bundled `Render/Shaders/*.metal` (resource folder) or from inline strings (`Render/ShaderSources.swift`, regenerated by `scripts/gen_inline_shaders.sh` after any `.metal` change).

## Session / bridge (dir `Sources/VeyraCore`, `Sources/Framelift/Session`)
```swift
struct ConsoleCredentials { var accountID: Data /*8*/; var registKey: Data /*16*/; var morning: Data /*16*/ }
struct PairedConsole: Codable, Identifiable, Hashable { var id: String /*console MAC hex*/; var nickname: String; var host: String; var lastSettings: StreamSettings? }
struct DiscoveredConsole: Identifiable, Hashable { var id: String; var address: String; var name: String; var isPS5: Bool; var standby: Bool }
enum SessionEvent { case connected, loginPinRequired, quit(reason: Int32, message: String), failed(code: Int32, message: String) }

final class ConsoleStore: ObservableObject {           // owner-only files for keys, UserDefaults for list
    static let shared: ConsoleStore
    @Published private(set) var consoles: [PairedConsole]
    func credentials(for consoleID: String) -> ConsoleCredentials?
    func save(_ console: PairedConsole, credentials: ConsoleCredentials) throws
    func update(_ console: PairedConsole)
    func remove(_ consoleID: String)
    var psnAccountIDBase64: String? { get set }        // remembered PSN account id (UserDefaults)
}
enum PSNAccount { static func decode(base64OrDecimal: String) -> Data? }   // 8 bytes
enum ConsolePairing { static func pair(host: String, accountID: Data, pin: String) async throws -> (PairedConsole, ConsoleCredentials) }
enum ConsoleDiscovery { static func discover(timeout: TimeInterval) async -> [DiscoveredConsole]; static func wake(host: String, credentials: ConsoleCredentials) async -> Bool }

final class RemotePlaySession: ControllerSink {
    init(host: String, credentials: ConsoleCredentials, settings: StreamSettings)
    var onVideo: ((EncodedVideoUnit) -> Void)?           // called on core thread
    var onAudio: ((PCMChunk) -> Void)?
    var onEvent: ((SessionEvent) -> Void)?               // delivered on main queue
    var onFeedback: ((ControllerFeedbackEvent) -> Void)? // core thread
    func start() throws
    func stop()                                          // blocking join, call off main if possible
    func submitLoginPin(_ pin: String)
    func requestKeyframe()
    func send(_ state: ControllerSnapshot)
    var stats: VRStats { get }
}
```

## App / UI (dir `Sources/Framelift/App`)
SwiftUI `@main` app: console list, pairing, settings (display picker, fullscreen, bitrate, frame generation options, touchpad, performance overlay, debug logs), the stream window (fullscreen on the chosen display), and the telemetry overlay. `StreamCoordinator` wires the PS5 session → decoder → presentation engine, audio and input. With the "Debug logs" setting on, `Diagnostics` writes `events.log` and `frames.csv` per stream to `~/Library/Logs/Framelift/<session>/`.
